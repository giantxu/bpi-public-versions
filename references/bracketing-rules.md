# Bracketing rules – default set and decisions to put to the user

The submitter ("own company") is usually one party of each document; the counterparties are third parties.
Under 19 C.F.R. § 165.4(d) the public version may only contain the submitter's own information or public
information, so third-party identity and negotiated terms are bracketed.

## Default rules (worked well; confirm with the user)

| Item | Treatment | Public label |
|---|---|---|
| Supplier / contractor / forwarder / consultant name, abbreviation, logo, letterhead, address, phone, fax, e-mail, website, registration no. | bracket every occurrence (body text too: "the Supplier XYZ shall…" → "[Supplier] shall…") | Supplier name / Supplier name and address / Supplier logo / Third-party name |
| Supplier seals incl. cross-page seal fragments; all handwritten signatures and page initials (both parties) | bracket | Seal / Signature / Initials |
| Names of individuals (sales staff, legal reps, project managers, approvers, drivers), ID / IC numbers, personal phones | bracket | Name(s) |
| Bank names + account numbers, SWIFT, tax IDs of the supplier; **the submitter's own account and tax numbers** (privacy rule) | bracket | Bank account / tax ID information |
| Prices, amounts (figures **and** words), cumulative amounts, totals, provisional sums, rates per day | bracket | Amount / Total contract price |
| Price lists / BOQs: quantity + unit price + amount columns, one block per page; keep headers and item descriptions | bracket | Quantities, unit prices and amounts |
| Payment clauses, payment ratios, retention / warranty bond %, liquidated damages & penalties, termination payments, deferred-payment schedules, rush-work rewards | bracket the **whole clause** in every language version | Payment terms (percentages, amounts and timing) / Liquidated damages terms / Payment schedule |
| Handwritten notes stating payment terms (e.g. "72% of first batch") | bracket | Handwritten note (payment terms) |
| Submitter's own name, address, phone, post code, own bank **name**, own seal | public (bracket the own seal only where a signature crosses it) | – |
| Contract / project numbers, dates, project names, equipment names and specifications, technical annexes, generic legal boilerplate (force majeure, arbitration, anti-bribery deduction clauses, interest-on-late-payment mechanics if generic) | public | – |
| Archive / filing numbers handwritten by the submitter | public | – |

## Decisions to ask the user (record answers in _work/rules.md)

A. Is supplier identity confidential everywhere? (Default yes – largest effect on volume.)
B. Bracket quantities in price lists, or only prices? (Default: both, like CBP's Appendix II example; leave
   quantities public only if the user needs them to prove capacity.)
C. Document numbers that contain a supplier abbreviation (e.g. "ABC-XYZ-2023-03" where ABC is the supplier's initials) – bracket the whole number? (Bracketing the
   whole number is the safer choice.)
D. Payment / LD clauses – whole clause or only the numbers? (Default whole clause – cleaner and safer.)
E. Word translations – deliver as PDF (default; consistent with originals) or as .docx?
F. Names of the submitter's own staff (signatures, approvers, employees on internal forms) – bracket? (Default
   yes as personal information; flag it in the report.)
G. Standard-form contract defaults (e.g. a 50% safety-fee prepayment written into general conditions) – bracket?
   (Default: bracket only if the clause states a concrete negotiated figure; flag.)
H. Third parties other than the main supplier (designers, supervisors, landlords, forwarders, customs brokers) –
   treat like suppliers? (Default yes.)

## Consistency rules learned the hard way

- The original and every translation of it get the same brackets (same clauses, same names).
- The same clause type gets the same treatment in every folder – when several reviewers work in parallel, compare
  their judgement calls and harmonise (e.g. one bracketed an anti-bribery clause, others left it public).
- Overlay translations (scan + red translated text): the red text is not a seal; but translated text repeating BCI
  is bracketed.
- When a box would only cover half a company name or the label words of a field, extend it – partial names leak.
